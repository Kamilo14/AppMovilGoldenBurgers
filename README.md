GoldenBurgers App – Aplicación Móvil

Aplicación móvil desarrollada para el local GoldenBurgers, diseñada para ofrecer a los clientes una experiencia rápida, moderna y fácil de usar al realizar pedidos, gestionar su perfil y explorar el catálogo de productos.

-Fabian Basaes
-Luckas Trujillo

Funcionalidades Principales

🔐 Autenticación

-Registro de nuevos usuarios.

-Inicio de sesión con credenciales.

-Manejo de autenticación mediante JWT y FireBaseAuthentication.

🍔 Catálogo y Productos

-Visualización completa del catálogo de productos disponibles.

-Búsqueda por categorías.

-Agregar productos a favoritos.

-Ver detalle del producto.

🛒 Carrito de Compras

-Selección de productos y suma automática del total.

-Visualización del carrito en tiempo real.

-Modificación de cantidades.

-Eliminación de productos.

💳 Checkout & Pago

-Pantalla de Checkout para completar datos faltantes del cliente.

-Proceso de pago simulado para confirmar el pedido.

-Generación del pedido final.

👤 Perfil del Usuario

-Visualización y edición del perfil.

-Actualización de nombre, teléfono, dirección, etc.

-Carga de imagen de perfil (opcional).

-Acceso al historial de pedidos.

🌙 Personalización

Implementación de modo oscuro.
